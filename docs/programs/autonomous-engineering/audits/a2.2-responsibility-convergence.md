# A2.2 — Responsibility Convergence

## Current State

### EngineeringAutomationPipeline

- Owns orchestration
- Owns stage sequencing
- Owns execution lifecycle

### EngineeringService

Currently delegates to:

- EngineeringCompletionOrchestrator
- Runtime Lifecycle

No engineering execution capability exists.

## Target State

EngineeringAutomationPipeline

- Orchestrates only.
- Never performs engineering work.

EngineeringService

- Owns engineering work execution.
- Delegates to:
  - Runtime Lifecycle
  - Knowledge
  - Governance
  - Completion
  - Organizational Memory

Execution Lifecycle

- Owns execution state transitions.

EngineeringExecutionStore

- Owns persistence.

EngineeringExecutionValidation

- Owns validation.

## Result

ExecuteStage should invoke EngineeringService rather than acting as a placeholder lifecycle transition.
