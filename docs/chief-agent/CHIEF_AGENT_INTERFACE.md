# Chief Agent Interface

Status: Approved

Version: 1.0

---

# Purpose

This document defines the executive interface of the KoreLumina Chief Agent.

The Chief Agent is the primary operating interface of KoreLumina.

It is not a chat application.

Conversation is one capability within the executive interface.

---

# Design Goals

The interface must:

- Provide complete operational visibility
- Surface priorities instead of raw data
- Support mission-based execution
- Minimize context switching
- Expose platform health
- Enable human approval
- Make AI decisions explainable
- Present institutional knowledge as operational intelligence

---

# Executive Dashboard

The landing page presents a complete operational briefing.

Sections:

- Daily Briefing
- Mission Health
- Platform Health
- Runtime Health
- Knowledge Health
- Agent Activity
- Pending Approvals
- Recommendations
- Current Mission
- Recent Decisions

The dashboard answers one question:

"What should happen next?"

Displays every specialist agent.

# Execution Center

Displays live execution.

- deployments
- recovery
- repository changes

- canonical knowledge promotion

- evidence
- recommendation
- risk

- rollback strategy

---

# Activity Center

- missions

- deployments
- approvals

- recovery

# Conversation Panel

Conversation is a docked capability.

The conversation panel:

- answers questions
- explains decisions
- generates plans
- summarizes activity
- retrieves knowledge

Conversation never replaces the executive dashboard.

# Daily Briefing

Every session begins with a briefing.

The briefing summarizes:

- work completed
- work remaining
- current priorities
- risks
- recommendations
- pending approvals

The briefing establishes operational context before work begins.

---

# Interface Principles

The Chief Agent interface follows these principles:

- Executive-first
- Mission-oriented
- Explainable
- Observable
- Approval-driven
- Knowledge-backed
- Production-focused
- Minimal context switching
- Human authority preserved

---

# Success Criteria

The interface succeeds when an engineer can answer the following within one minute:

- What is the platform doing?
- What should happen next?
- What is blocked?
- What requires approval?
- Which agent is responsible?
- What knowledge supports this decision?
- What recovery path exists?
