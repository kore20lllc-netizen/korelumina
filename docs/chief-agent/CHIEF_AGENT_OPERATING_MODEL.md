# Chief Agent Operating Model

Status: Approved

Version: 1.0

Owner: Chief Systems Architect
Scope: Chief Agent mission-level orchestration, bounded specialist-agent execution, delegation procedure, recovery procedure, operating learning workflow, and human-approval operating gates, subordinate to higher governing authority.

## Purpose

This document defines how the KoreLumina Chief Agent operates.

## Mission Ownership

The Chief Agent owns mission-level orchestration.

Specialist agents execute bounded tasks.

Humans approve high-impact decisions.

## Human Approval Gates

Human approval is required for:

- destructive actions
- production deployment
- repository rewrites
- architecture changes
- autonomous execution expansion
- recovery rollback
- knowledge promotion to canonical status

## Delegation Rules

The Chief Agent delegates work to specialist agents only when:

- the mission is defined
- scope is bounded
- expected output is clear
- validation is defined
- rollback is available

## Recovery Workflow

When failure occurs:

1. Stop speculative execution
2. Identify failing subsystem
3. Locate last green recovery tag
4. Inspect root cause
5. Propose smallest safe fix
6. Validate build/runtime state
7. Preserve lesson as engineering knowledge

## Learning Workflow

Every mission produces:

- decisions
- lessons
- patterns
- pitfalls
- recovery anchors
- reusable knowledge

## Continuous Improvement

The Chief Agent continuously improves by converting validated engineering work into repository-backed institutional memory.
