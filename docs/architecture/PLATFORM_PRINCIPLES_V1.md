# 1. Purpose
-------------------------------------------------------------------------------

The Platform Principles define the permanent engineering and architectural
principles that govern KoreLumina.

Principles outlive implementations.

Principles outlive versions.

Principles guide every architectural decision.

-------------------------------------------------------------------------------
# 2. Architectural Principles
-------------------------------------------------------------------------------

Runtime is the execution authority.

Repository Intelligence is the repository authority.

AI assists engineering.

Enterprise governs organizations.

Platform Extensions extend capabilities.

Customers retain ownership.

-------------------------------------------------------------------------------
# 3. Engineering Principles
-------------------------------------------------------------------------------

-------------------------------------------------------------------------------
# 4. Operational Principles

# 6. Architectural Invariants
-------------------------------------------------------------------------------

The following architectural rules are permanent.

-------------------------------------------------------------------------------

Runtime is the execution authority.

Repository Intelligence owns repository understanding.

AI generates engineering intent and Drafts.

Deployment delivers validated Runtime artifacts.

Enterprise governs organizations.

Engineering Platform provides internal engineering capabilities.

Platform Extensions extend, never replace, platform capabilities.
