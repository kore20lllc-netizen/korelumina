-------------------------------------------------------------------------------
MISSION
-------------------------------------------------------------------------------

KoreLumina is not an AI Builder.

KoreLumina is a continuously learning software engineering platform.

The Builder is one interface.

The Runtime is one execution environment.

The Knowledge Preservation Platform is the operating system.

The Chief Agent is the primary engineer.

Everything in KoreLumina exists to continuously acquire, preserve,
understand, improve, and reuse engineering knowledge.

-------------------------------------------------------------------------------
THE THREE FOUNDATIONAL PRINCIPLES
-------------------------------------------------------------------------------

Everything in KoreLumina shall prioritize these principles.

Tier 1

Knowledge Preservation

Tier 2

Chief Agent

Tier 3

UI Contract

All remaining systems exist to support these principles.

-------------------------------------------------------------------------------
PRINCIPLE 1

KNOWLEDGE PRESERVATION IS THE FOUNDATION
-------------------------------------------------------------------------------

The Knowledge Preservation Platform (KPP) is the highest priority subsystem
inside KoreLumina.

Every subsystem shall contribute knowledge.

Every engineering action shall be capturable.

Every decision shall become reusable knowledge.

Nothing valuable should disappear.

Knowledge is a permanent asset.

Features are temporary.

Knowledge is forever.

-------------------------------------------------------------------------------
PRINCIPLE 2

THE CHIEF AGENT IS THE PRIMARY ENGINEER
-------------------------------------------------------------------------------

The Chief Agent is the primary consumer of the Knowledge Preservation
Platform.

Every subsystem should ask

"What can the Chief Agent learn from this?"

before asking

"Does this feature work?"

The Chief Agent continuously improves through

• Knowledge compilation

• Organizational memory

• Architecture memory

• Learning patterns

• Repository history

• Runtime observations

• Human decisions

• Engineering reviews

• Failures

• Recoveries

Every reconstruction should improve the Chief Agent.

-------------------------------------------------------------------------------
CHIEF AGENT RESPONSIBILITIES
-------------------------------------------------------------------------------

The Chief Agent

• Learns

• Plans

• Reviews

• Coordinates

• Preserves knowledge

• Detects architectural drift

• Guides engineering

• Improves future engineering decisions

The Builder exists to empower users.

The Knowledge Platform exists to empower the Chief Agent.

-------------------------------------------------------------------------------
PRINCIPLE 3

THE UI IS THE CONTRACT
-------------------------------------------------------------------------------

The UI defines the product.

The implementation satisfies the UI.

Never redesign the UI to match implementation limitations.

Redesign the implementation to satisfy the UI contract.

The UI defines

• Experience

• Workflow

• Interaction

• User expectations

Everything beneath the UI exists to fulfill that contract.

Builder

↓

Domain Model

↓

Knowledge

↓

Runtime

↓

Persistence

↓

Infrastructure

Never the reverse.

Architecture,

it should be reconsidered.
