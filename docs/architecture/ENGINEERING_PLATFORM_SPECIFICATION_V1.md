# 1. Purpose

The Engineering Platform provides internal engineering capabilities used by
KoreLumina engineers.

It extends the platform with professional engineering services while preserving
architectural boundaries.

Engineering tooling never replaces Runtime.

Engineering tooling never bypasses Runtime.
