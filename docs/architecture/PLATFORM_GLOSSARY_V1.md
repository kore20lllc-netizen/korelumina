# 1. Purpose
-------------------------------------------------------------------------------

The Platform Glossary defines the canonical terminology used throughout the
KoreLumina architecture.

Every specification uses these definitions.

Definitions remain stable.

-------------------------------------------------------------------------------
# 2. Core Terminology
-------------------------------------------------------------------------------

Architecture

The long-term structural design of KoreLumina.

-------------------------------------------------------------------------------

Platform

A major subsystem with defined ownership and responsibilities.

-------------------------------------------------------------------------------

Subsystem

A logical component within a platform.

-------------------------------------------------------------------------------

Runtime

The execution authority responsible for running customer software.

-------------------------------------------------------------------------------

Repository

Customer-owned source code imported into KoreLumina.

-------------------------------------------------------------------------------

Workspace

An isolated Runtime environment associated with a project.

-------------------------------------------------------------------------------

Project

A customer software application managed by KoreLumina.

-------------------------------------------------------------------------------

Draft

A proposed repository modification requiring approval before Runtime applies
it.

-------------------------------------------------------------------------------

Artifact

A validated deployable output produced from Runtime.

-------------------------------------------------------------------------------

Deployment

The promotion of validated artifacts into a target environment.


-------------------------------------------------------------------------------
# 3. Runtime Terminology
-------------------------------------------------------------------------------

Universal Runtime

The execution authority responsible for running customer software.

-------------------------------------------------------------------------------

Runtime Instance

A running execution environment for a single workspace.

-------------------------------------------------------------------------------

Runtime Event

An immutable event emitted by Runtime describing operational activity.

-------------------------------------------------------------------------------

Preview

A live execution view generated by Runtime.

-------------------------------------------------------------------------------

Execution Engine

The Runtime subsystem responsible for executing customer software.

-------------------------------------------------------------------------------

Workspace Manager

The Runtime subsystem responsible for workspace lifecycle.

-------------------------------------------------------------------------------

Draft Engine

The Runtime subsystem responsible for validating and applying approved Drafts.

-------------------------------------------------------------------------------

Filesystem Engine

The Runtime subsystem responsible for repository filesystem operations.

-------------------------------------------------------------------------------

Health Engine

The Runtime subsystem responsible for Runtime health reporting.

-------------------------------------------------------------------------------
# 4. AI Terminology
-------------------------------------------------------------------------------

AI Platform

The platform responsible for engineering intelligence.

-------------------------------------------------------------------------------

Intent

The engineering objective inferred from customer requests.

-------------------------------------------------------------------------------

Plan

A structured engineering strategy produced by the AI Platform.

-------------------------------------------------------------------------------

Draft Generation

The process of producing reviewable repository modifications.

-------------------------------------------------------------------------------

Validation

The verification of AI-generated engineering outputs.

-------------------------------------------------------------------------------

Model Router

The subsystem responsible for selecting AI providers.

-------------------------------------------------------------------------------

Repository Context

The structured repository knowledge supplied to AI.

# 5. Repository Intelligence Terminology
-------------------------------------------------------------------------------

Repository Intelligence Platform

The platform responsible for understanding customer repositories.

-------------------------------------------------------------------------------

Repository Manifest

The canonical structured representation of a repository.

-------------------------------------------------------------------------------

Framework Detection

Identification of the primary application framework.

-------------------------------------------------------------------------------

Architecture Map

A structured representation of repository architecture.

-------------------------------------------------------------------------------

Capability Scan

Analysis of repository capabilities and supported features.

-------------------------------------------------------------------------------

Dependency Analysis

Evaluation of repository dependencies and relationships.

-------------------------------------------------------------------------------

Repository Knowledge Store

Persistent structured knowledge generated from repository analysis.

-------------------------------------------------------------------------------
# 6. Enterprise Terminology
-------------------------------------------------------------------------------

Enterprise Platform

The platform responsible for governance.

-------------------------------------------------------------------------------

Organization

The highest administrative boundary within KoreLumina.

-------------------------------------------------------------------------------

Policy

A rule governing platform behavior.

-------------------------------------------------------------------------------

Budget

A customer-controlled spending limit.

-------------------------------------------------------------------------------

Compliance

Verification against regulatory or organizational requirements.

-------------------------------------------------------------------------------

Audit Record

An immutable operational record.

-------------------------------------------------------------------------------

RBAC

Role-Based Access Control governing permissions.


-------------------------------------------------------------------------------
# 7. Deployment Terminology
-------------------------------------------------------------------------------

Deployment Platform

The platform responsible for delivering validated Runtime artifacts.

-------------------------------------------------------------------------------

Deployment Artifact

A validated package produced by Runtime and ready for deployment.

-------------------------------------------------------------------------------

Deployment Environment

A target environment where artifacts are executed.

-------------------------------------------------------------------------------

Rollback

The restoration of a previously validated deployment.

-------------------------------------------------------------------------------

Release Candidate

A production-ready build awaiting final approval.

-------------------------------------------------------------------------------

Environment Promotion

The controlled movement of artifacts between deployment environments.

-------------------------------------------------------------------------------
# 8. Observability Terminology
-------------------------------------------------------------------------------

Observability Platform

The platform responsible for operational visibility.

-------------------------------------------------------------------------------

Metric

A numerical measurement describing platform behavior.

-------------------------------------------------------------------------------

Log

A structured record describing an operational event.

-------------------------------------------------------------------------------

Trace

A correlated sequence of operations across platform boundaries.

-------------------------------------------------------------------------------

Health Check

A verification of subsystem operational status.

-------------------------------------------------------------------------------

Alert

A notification generated from observable operational evidence.

-------------------------------------------------------------------------------

Correlation Identifier

A unique identifier linking related platform activities.


-------------------------------------------------------------------------------
# 9. Engineering Terminology
-------------------------------------------------------------------------------

Engineering Platform

The internal platform responsible for professional engineering services.

-------------------------------------------------------------------------------

Repository Audit

A structured engineering assessment of a customer repository.

-------------------------------------------------------------------------------

Modernization

The process of upgrading software to current engineering standards.

-------------------------------------------------------------------------------

Migration

The controlled transition of software between architectures, frameworks, or
platforms.

-------------------------------------------------------------------------------

Professional Services

Internal engineering engagements delivered by the Engineering Platform.

-------------------------------------------------------------------------------

Engineering Console

-------------------------------------------------------------------------------

Engineering Knowledge Base
