# 1. Purpose

This document defines the mandatory production engineering workflow for every capability implemented within KoreLumina.

Its purpose is to ensure every implementation follows a repeatable, production-grade engineering process while continuously improving both the platform and the Engineer Agent.

No roadmap item may bypass this workflow.

---

# 2. Engineering Philosophy

Every implementation shall simultaneously increase:

• Customer Value

• Platform Capability

• Engineering Capability

• Organizational Knowledge

• Engineer Agent Capability

Implementation is therefore a production engineering activity and a learning activity.
