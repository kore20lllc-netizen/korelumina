# Purpose

This document defines how operators move throughout Knowledge Operations.

Navigation is not page navigation.

Navigation is movement through organizational understanding.

Operators should always know:

where they are

how they arrived

what they are investigating

where they can go next

without losing context.

---

# 1. Philosophy

Knowledge Operations is one workspace.

Not many pages.

The workspace continuously transforms around the operator.

Context is preserved.

Only emphasis changes.

---

# 2. Primary Navigation Principle

Navigation changes perspective.

It does not replace the environment.

Every transition preserves:

selection

history

breadcrumbs

filters

time

relationships

focus

investigation state

The operator never starts over.

---

Executive Situation

↓

# 4. Navigation Layers

Navigation exists in four layers.

Global Navigation

↓

Operational Navigation

↓

Context Navigation

↓

Object Navigation

Each layer answers a different question.

---

# 5. Global Navigation

Global Navigation changes major Lumina workspaces.

Examples:

Projects

Designer

Developer

Runtime

Knowledge Operations

Chief Agent

Global navigation never changes while inside Knowledge Operations.

---

# 6. Operational Navigation

Operational Navigation changes investigative perspective.

Examples:

Situation

Flow

Validation

Memory

Graph

Governance

Timeline

Journey

The environment remains intact.

---

# 7. Context Navigation

Context Navigation changes the current investigation.

Examples:

Architecture

Engineering

Security

Operations

Customer

Infrastructure

Product

Mission

The workspace adapts without losing continuity.

---

# 8. Object Navigation

Selecting a Knowledge Object establishes a new operational focus.

Everything reorganizes around the selected object.

Relationships remain visible.

History remains accessible.

---

# 9. Persistent Context

The following remain persistent across navigation:

selected object

time range

filters

domain

breadcrumbs

comparison state

journey state

operator workspace

Nothing important resets unexpectedly.

---

Not file hierarchy.

# 13. Investigation Continuity

Operators may suspend investigations.

Returning later restores:

selection

inspector

comparison

timeline

zoom

filters

annotations

The workspace remembers context.

---

# 14. Spatial Continuity

Transitions should communicate:

movement

focus

hierarchy

context

Nothing abruptly disappears.

Nothing teleports.

Operators maintain orientation.

Every Knowledge Object supports transitions to:

---

# 17. Search Navigation

Search is contextual.

Results never replace the workspace.

Instead:

search centers the workspace

focus shifts

graph recenters

memory highlights

validation opens

The environment remains continuous.

---

# 18. Comparison Navigation

Comparison becomes a temporary navigation state.

Supported comparisons:

knowledge

versions

architectures

patterns

lessons

procedures

The operator exits comparison without losing context.

---

# 19. Notifications

Notifications are navigable.

Selecting a notification transports the operator directly into the
relevant investigation.

No intermediate screens.

---

# 20. Deep Linking

Every operational state has an address.

Examples include:

selected object

journey

timeline

comparison

validation case

memory object

graph focus

executive situation

Deep links reconstruct the exact workspace.

---

# 21. History

Navigation history records investigations.

Back returns to the previous investigation state.

Not merely the previous screen.

History preserves reasoning.

---

# 22. Multi-Selection

Operators may maintain multiple active investigations.

Examples:

comparison

validation batches

related objects

architecture reviews

Context remains organized.

Never confusing.

---

# 23. Accessibility

Navigation supports:

keyboard-first operation

screen readers

semantic landmarks

reduced motion

focus restoration

logical traversal

Every navigation path remains accessible.

---

# 24. Performance

Navigation should feel immediate.

Heavy views progressively reveal detail.

Context restoration should appear instantaneous.

Operators should never wait for unnecessary reloads.

---

# 25. Anti-Patterns

Knowledge Operations must never become:

page-based

wizard-driven

modal-heavy

tab-centric

breadcrumb-dependent

folder-oriented

file-oriented

Navigation serves investigation.

Not application structure.

---

# 26. Certification

The Information Architecture is certified only when:

• Operators never lose context.

• Every perspective preserves identity.

• Journey Mode follows knowledge lifecycle.

• Search enhances rather than interrupts investigation.

• Deep links recreate complete operational state.

• Breadcrumbs communicate reasoning rather than hierarchy.

• Navigation reinforces one continuous workspace.

• Every transition strengthens spatial understanding.

• Knowledge Objects remain the center of navigation.

• Knowledge Operations feels like a single living environment rather than a collection of pages.
