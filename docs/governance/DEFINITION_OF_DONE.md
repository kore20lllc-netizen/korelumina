# Definition of Done

An engineering task is complete only when all conditions below are satisfied.

---

## Implementation

- Specification implemented
- Production-grade code
- No known regressions

---

## Validation

- Runtime build passes
- Builder build passes
- Functional validation completed

---

## Architecture

- Architectural review completed
- No constitutional violations
- No governance violations

---

## Knowledge

- Knowledge Platform updated
- ADRs updated (if applicable)
- Decision Memory updated (if applicable)
- Engineering Memory updated (if applicable)

---

## Reconciliation

- Architectural reconciliation completed
- Lessons learned recorded
- Approved improvements captured

---

## Repository

- Atomic commit
- Push completed
- Clean repository state
